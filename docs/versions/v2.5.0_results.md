## 1. Version question and verdict

Question: does replacing the learned safety certificate with an exact, policy-independent
analytic maneuver-family barrier V_M = min_m max_k h(x_k^m) (|M| = 17, shift-closed,
beta = 0) remove the v2.4.x failure classes, and does joint training on top of it recover
learned-SOTA performance?

Verdict: **safety axis closed positive; performance axis not recovered — bottleneck
identified, quantified, and localized to the policy side.**

- Safety: exact by construction (eps_0 = 0, no bootstrap), nominal-independent invariance
  verified in-system for the first time: collision confined to a tight band across all 20
  checkpoints of a 30k-step policy-only JT run, in **2 full runs** (Stage-B 0.0035–0.0065;
  B-2 0.0020–0.0060; a third run is a 3-checkpoint partial with no reselect series and adds
  no per-checkpoint evidence) — R10. Best collision 0.0055 [0.0025, 0.0090] vs learned
  SOTA 0.0090.
- Performance: cps_v2 0.8327 [0.8053, 0.8564] (B-2 best, D-slow) / 0.8358 (D-fast) vs the
  learned cluster ~0.88–0.90. Exact gap decomposition (R8, arithmetic-gated): vs v2.3.0
  seed42, Delta cps_v2 = -0.0683 = reach -0.0300 (44%) + stuck -0.0235 (34%) +
  empty-intersection -0.0168 (25%) + timeout -0.0050 (7%), offset by collision +0.0070 in
  B-2's favor. (vs the 3-seed mean: -0.0678 with the same structure.) The reach/stuck/
  timeout share is the guidance vacuum (below); the empty-intersection share reflects B-2's
  3x higher boundary-band infeasible-step rate (0.0836 vs 0.0275), co-located with the
  boundary chattering at stalls (interpretation grade).

Root cause of the liveness share — **interior guidance vacuum**: V_M is exactly -1 on the
certified interior, so neither the filter nor a terminal-V term carries navigation signal;
the learned V-hat's inaccurate interior gradient had been doubling as guidance. Measured
credit-horizon gap: open-area stall detour payback 4.65–7.85 s vs the 1.5 s BPTT window
(100% beyond).

## 3. Stage verdicts

**Stage A (training-free, LQR nominal).** Witness theorem quantitatively verified:
empty-intersection 0.7–1.5% on the certified set vs ~95% off it; certified-start collisions
traced to the certificate grid (below). Monotone augmentation measured (|M| 5 -> 9 -> 17:
stuck 0.067 -> 0.0535 -> 0.049). Canonical-metric semantics defect discovered (far-field
flat-singular inflation) -> cps_v2.

**G7 + deploy-rate + ARM-G/K (grid law).** Collision floor (~0.0055) is margin-invariant
for gamma_m in {0.02, 0.05} (P-A4 refuted) and is certificate-grid optimism: coll scales
as dt_Vm^1.37 (0.0055 -> 0.0010 at 0.01); 0.15% of starts flip certified(0.05) ->
uncertified(0.01) (ARM-G); knee dt_Vm = 0.025 gives cert-coll 0.00102 (ARM-K). Theory:
inter-sample excursion cap delta_grid = v_max*dt/2 = 0.0625 > both tested margins —
consistent with the invariance (Rev.3 prop:gridres). Rule adopted: dt_Vm = safety knob,
dt_ctrl = liveness knob (02_control §8).

**Fast path.** torch.compile V_M 4.9x (1.0 -> 0.204 s/step). Trajectory bit-parity proven
unattainable for the branch-discrete projection (reference self-flips under 1e-7 jitter);
equivalence standard replaced by function parity + safety equivalence; all verdict V_M
comparisons re-baselined fast-vs-fast. Production default VM_FAST=1; parity suite re-run
required per torch pin change.

**Stage B (policy-only JT, K_V = 0).** Structural safety confirmed (P-B2; R10 census
above). Liveness peaked ~step 7.5–9k then drifted (R1: delta cps -0.0589 = reach -0.0295 +
stuck +0.0285; safety flat; timeout flat — guidance-vacuum-consistent; sole-cause
attribution remains open).

**Stage B-2 (filter friction w = 0.05).** Weak positive (cps_v2 0.8254 -> 0.8327, stuck
0.049 -> 0.043) with safety intact (P-F3), but the motivating gauge hypothesis REFUTED:
active-band proj_mag unchanged 1.335 ~ 1.341 (P-F1); the gain is an open-area behavioral
effect (P-L4: 80% of the stuck reduction). P-F2/P-F4 refuted.

**lever1 + stall geometry (authoritative counts, R11).** Decel-turn REFUTED (rescued
0.9%). Stall clusters (n = 21, B-2 best): start-geometry {open-area 15, narrow_gap 5,
