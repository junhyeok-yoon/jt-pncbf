# v2.5.1 — Certified Policy Iteration → exact single-backup certificate. RESULTS

Closed 2026-07-13. Base: v2.5.0 (CLOSED). Strategist-authored verdict document
(`06_workflow` §2.6). Facts are disk-cited; per-phase build reports
(`phase_i0_report.md`, `phase_i1_loop_report.md`, `phase_i2_deconfound_report.md`,
`phase_i3_perf_report.md`) hold the raw records. **DI SOTA is unchanged: v2.3.0 —

## 1. Headline

The 17-maneuver hand-designed library is **removed from the method on both sides** — as
the certificate and as the filter — at no measured performance cost and with a stronger
safety guarantee.

- **Filter side.** The exact **unclipped single-backup certificate** ($V_{m_0}$: the
  deadband brake's stopping value, a differentiable 25-step rollout) run as the safety
  channel gives pooled 3-seed arm-A **cps_v2 0.8160 [0.801, 0.829]**, collision **0.0018**
  — statistically indistinguishable from the v2.5.0 17-maneuver barrier (0.8327
  [0.805, 0.856], collision 0.0055; CIs overlap heavily) while using **one** backup
  controller instead of a designed library.
- **Certificate side.** The learned bail-out family
  ($\{m_0\} \cup \{$transport $j$-step prefixes then $m_0\}$) certifies **more** volume
  than the 17-maneuver library: cert-ratio $V_k / V_{\mathcal M17}$ = **1.0133 → 1.0155**
  across iterations, recovering **96–99%** of the single-backup gap set. No hand-designed
  maneuver participates.
- **Safety.** The S′ shield (every-step successor verification of geometric clearance +
  brake fallback) held **zero verified-start collisions in every dual-arm evaluation of
  this version** (~16 evaluations × 2000 episodes). The best shielded configuration is
  **E_s99 arm-B: cps_v2 0.8422 with collision exactly 0.000** — the highest-performing
  guarantee-carrying configuration in the project to date.
- **Performance gate.** The registered CPI performance gate (P-PI2, filter-only arm-A
  cps_v2 ≥ 0.83 within 3 iterations of the *learned*-certificate loop) was **REJECTED**
  (0.678 / 0.721 / 0.660). That rejection stands as recorded; the E-axis result above is
  a separate, later registration (P-E1/P-E2), not a rescue of it.

## 2. What was tested, and why

v2.5.0 closed with two systems and no way to have both properties at once: the learned
filter (v2.3.0, cps_v2 0.9005, no guarantee) and the exact analytic barrier (0.8327,
structural safety, but an *interior guidance vacuum* — clipped values are flat at −1
across the certified interior, so the filter and terminal carry no gradient there). The
Researcher additionally rejected the 17-maneuver library as part of the method: in high
dimensions there is no such oracle, and PNCBF's value proposition is that the certificate
is **learned from data**.

v2.5.1 therefore ran the Certified Policy Iteration line: value by **complete-MC
supervised regression** (no bootstrap), policy by **frozen-certificate BPTT** (no RL), and
the residual absorbed at runtime by a **shield** whose guarantee does not depend on value
accuracy. The requirement set is dimension-neutral: **simulator + $h$ + one backup
controller**.

Four registered arcs were run: iteration-0 (foundation), the full loop (pathfinder),
deconfounding + two contingencies, and the E/D/S performance push.

## 5. Established results

**5.1 Safety is separable from certificate accuracy — demonstrated in-system.** Across
every configuration in this version, the same policy that collides 2.4–5.9% of the time
under a filter-only deployment collides **exactly 0** times (verified-start episodes)
under the S′ shield. The shield's invariant is maintained by construction: before applying
any action, [one control segment + brake-to-rest from the successor] is verified on a
refined grid ($dt_{\text{check}} = 0.01$, geometric clearance margin
$v_{\max} dt_{\text{check}} / 2 = 0.0125$ m); on failure, the brake action is applied,
whose plan is the verified tail of the previous check. Neither $\hat V$, nor
$\varepsilon_q$, nor a margin appears in this chain. The iteration-0 calibration profile
independently justified this design *before* deployment: $\varepsilon_q(0.10) \le 0.047$
but $\varepsilon_q(0.01) \approx 0.79$ — the tail is far too heavy for a statistical
(margin-shift) shield to be meaningful.

**5.2 Cumulative family retention is necessary and sufficient for monotonicity.** The
theorem $\mathcal F_{k+1} \supseteq \mathcal F_k \Rightarrow V_{k+1} \le V_k$ pointwise
(monotone augmentation, `02_control` §8) requires the family to retain **all** prior
transports. The single-step form specified in the original Appendix (retain only the
previous transport) was **refuted** by measurement — 53,610 pointwise violations at
$k{=}3$, because $\mathcal F_3 = \{m_0, T_3, T_2\} \not\supseteq \mathcal F_2 =
\{m_0, T_2, T_1\}$ wherever $T_1$ was the argmin. This was a Strategist theory error, not
an implementation bug. The corrected cumulative family
$\mathcal F_k = \{m_0, T_1, \dots, T_k\}$ was verified at 0 violations in three
independent checks (A1 rebuild, A6 canonical refresh, P1.5 chain audit) on the fixed
1,241,100-state set. Cost is linear in $k$ (one extra prefix simulation per iteration).

**5.3 The bail-out family removes the hand-designed library, with margin.** On the
241k-state oracle subset: the single backup alone certifies 98.5% of the 17-maneuver
volume, and the gap set $G = \{V_{\mathcal M17} \le 0 < V_{m_0}\}$ is 77.7% explained by
the registered mechanism $C$ (positive closing speed toward the nearest obstacle **and**
surface distance within the stopping distance $\lVert v\rVert^2 / 2u_{\max}$). Adding
learned transports to the family recovers 96–99% of $G$ and pushes the cert-ratio **above
1.0** (1.0133 → 1.0152 → 1.0155). A learned policy prefix is a strictly better bail-out
member than a designed maneuver library, in this system.

**5.4 A learned certificate used as a raw CBF filter has a floor that certificate quality
does not remove.** This is the version's sharpest negative result, and it is the reason
the E axis exists. Filter-only deployment enforces a *differential* condition on
$\nabla \hat V$; it does not execute the certified plan. Consequences, all measured:
(i) frozen learned certificates admit 2.4–4.8% collisions where the exact barrier admits
0.55% and the exact backup 0.15%; (ii) **improving the certificate made deployment
worse** — the distribution-matched $\hat V_{2dm}$ achieved perfect on-policy calibration
($\varepsilon_q = 0$, P-P1a) and *raised* arm-A collisions 0.024 → 0.059, because the
conservatism slack that arm-A had been implicitly relying on (the learned value's
under-coverage of the policy corridor) was removed; (iii) the certificate chain kept
improving monotonically (§5.2, §5.3) through the same iterations in which the deployed
policy regressed. Certificate quality and filter-only deployment quality are **decoupled**.
The exact channel closes this gap by construction: the deployed $h$ *is* the certificate,
bit-identically (parity ≤ 1e-6 against the labeler's $j{=}0$ member).

**5.5 Unclipping restores the interior gradient.** The v2.5.0 vacuum was a property of the
$[-1,1]$ clip, not of exactness. The unclipped $V_{m_0}$ ranges to ≈ −3 in open space and
its zero level set is the exact stadium geometry (obstacle disk ⊕ the braking segment,
length $\lVert v \rVert^2 / 2u_{\max}$). Under it, reach rose to 0.909–0.914 and the
park-type stall phenotype — the signature of guidance vacuum — is **measured absent**
(0 of 104). This is a reparameterization of the same stopping-value function (zero sets
identical, no new field, no design freedom); it is not, and must never be described as, a
potential field.

**5.6 Warm-start is a real but sub-threshold improvement.** Policy-only warm-start
(`pi_init_ckpt`: load $\pi$ state, fresh optimizer/schedules/step/channel) gives a
per-seed paired gain of +0.060 / +0.078 / +0.063 with CIs excluding zero, and pooled
0.6741 → 0.7411 with disjoint CIs (a `04_eval` §5 significant improvement). It missed its
registered bar (≥ 0.75) by 0.009. The pathfinder's non-monotone iteration trajectory
(0.678 → 0.721 → 0.660) is therefore substantially fresh-init variance, not an iteration
effect.

**5.7 The residual stuck is policy-intrinsic chatter, not a shield or vacuum artifact.**
Classifying every stuck episode's last 100 steps: E2 (exact channel) 101 chatter / 0 park
/ 3 other of 104; R1 (learned channel) 122 / 0 / 5 of 127. The phenotype is
channel-invariant high-amplitude limit-cycle oscillation near goals and obstacles. This
explains, mechanistically, why both remaining levers failed or were void: the
minimal-intervention shield ladder cannot trim over-braking that isn't happening
(overrides ≈ 0.20/episode; P-S1 Δ = 0.0), and the horizon-summary terminal targets
park-type stalling that does not occur (W not run).

## 6. Refutation ledger (do not reintroduce without a new mechanism)

- **Bootstrapped critic co-trained with the policy** (P-B1): stuck 0.090 → 0.2245, reach
  0.857 → 0.720. The deadly-triad pathology this project excised from the safety channel
  in v2.4.x reappears identically in the *performance* channel. The failure is
  bootstrap + co-training, not horizon summarization per se; any revival must be
  complete-MC and frozen.
- **Distribution-matched labeling as a filter fix** (P-P1b/c): refuted, mechanism in §5.4.
  The pipeline itself (`cpi/collect_onpolicy.py`) is validated and retained; only the
  *hypothesis* (that arm-A collisions come from unlabeled policy-visited pockets) is dead.
- **Margin shift by $\varepsilon_q$**: void. The measured $\varepsilon_q(0.10) = 0$ makes
  the shift zero, and the $\alpha = 0.01$ tail (≈0.79) makes any usable shift absurd.
- **Behavior cloning from the plan-follower anchor** (P-D1): reach 0.0, oob 0.933. The
  clone is *faithful* (in-distribution action MSE 0.00095) — the anchor is a non-Markovian
  open-loop planner whose action depends on plan phase, so a reactive obs→action clone
  compounds error and leaves the world. Reviving distillation requires a closed-loop
  Markov expert or a DAgger-class correction, which is a new axis.
- **Single-step family retention** (§5.2): refuted with counterexample and measurement.
- Standing prohibitions from prior versions are unaffected (APF in any form, HOCBF,
  alpha-as-lever, disable_box, gradient/Sobolev supervision, BPTT horizon extension).

## 8. Open items, carried forward

1. **Chatter** is the entire remaining DI performance residual (stuck ≈ 0.052–0.058,
   ~97% chatter). Not attempted here. The natural single-axis candidate is a control-rate
   penalty in the policy stage cost (safety chain untouched); it requires its own
   registration and was deliberately not run inside a closing version.
2. **The learned certificate's role after E.** In DI the exact backup value is cheap
   enough to deploy directly, so the regressed $\hat V$ is not needed *for the filter*.
   Its remaining purposes are (a) amortization where the exact rollout is too expensive
   in the control loop, and (b) family membership, where learned transports already beat
   the designed library (§5.3). Which of these binds is a **dimension question**, not a
   DI question.
3. **Generality is the decisive test.** The method's claim is that
   simulator + $h$ + one backup controller suffices, with no re-design. The code
   inventory supports this: `signed_h` is position-only and system-generic, the pool
   builder, HardNet filter, nets, regression, calibration, audits, and dual-arm eval are
   already system-parameterized; the DI-specific surface is essentially **one primitive**
   (the deadband brake, shared by the labeler, the exact channel, and the shield) plus a
   handful of bounds lookups. v2.5.2 (unicycle) tests exactly this, and is theoretically
   non-trivial: a unicycle brake stops along its current heading, so the backup has **no
   lateral avoidance** and the certified set becomes heading-conditioned.
4. **Protocol amendments** raised by this version are listed as PROTOCOL FOLLOW-UP in the
   phase reports and are patched separately by the Strategist at close.
