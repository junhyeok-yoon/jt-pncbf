### 1.5 Why L2 imitation is the wrong form (derivation, then measured)

Projection Jacobian: with D the box-active diagonal mask and A_tilde = D·A,
du_safe/du_nom = D − A_tilde·A_tildeᵀ/||A_tilde||² — orthogonal projection onto the active
tangent space. Every downstream task gradient is therefore orthogonal to the active normal
cone, and the discrepancy delta = u_nom − u_safe lies entirely IN the normal cone
(delta = lambda*·A + clipped-coordinate components). Consequences: (i) L_normal
(normal-component imitation) is identical to L_agree off the box and strictly weaker on it —
withdrawn; (ii) task objective and L_agree do not compete pointwise on active steps, so w=3's
cps −0.0145 must be a state-chain effect; (iii) the blind direction is real but feeding it
(which L_agree did: d −25%) does not improve outcomes — measured.

## 3. The hazard's true 3-D form (gradient_alignment.md) — a premise audit that voided a mission

Deployed h_star (value_target_barrier + QuadrotorQuad3D.approach_barrier):

h_star = max{ phi(p_xy, o) + c_gain·(v_xy·r_hat), psi_up + c_z·v_z, psi_lo − c_z·v_z },
r_hat = unit horizontal vector to the nearest active cylinder; c_gain = 0.3;

grad_v h_star = c_gain·(r_x, r_y, 0) on the obstacle branch (purely horizontal) and
(0, 0, ±c_z) on the band branches (purely vertical, world frame). No R(q) anywhere.

exactly; z-fraction 0.0000 (obstacle, n=91) / 1.0000 (band, n=10); branch split 0.901 =
